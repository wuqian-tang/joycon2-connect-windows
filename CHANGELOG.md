# Changelog / 更新记录

## 1.1.0

- Portable Windows x64 app with a separate worker and bundled runtime.
- Responsive local UI, automatic initial theme, manual light/dark switch, and darker night appearance.
- Compact EN / 繁 / 简 language selection with system-language defaults.
- Live Joy-Con 2 button and stick visualization, guided pairing and localized status.
- Original flat controller icon for app, favicon and desktop shortcut.
- Driver/version/device readiness checks, documented build and dependency notices.

新增 Windows x64 便携版、自适应网页、明暗主题切换和三语言简写选择。加入实时按键与摇杆图示、配对引导、驱动配置检查，以及统一的扁平 JC 图标，并整理构建流程和依赖声明。
